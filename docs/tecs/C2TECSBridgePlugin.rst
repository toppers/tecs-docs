C2TECSBridgePlugin プラグインリファレンス
===================================================

名前
-------

  C2TECSBridgePlugin ... C 言語から TECS の受け口関数を直接呼び出すためのシグニチャプラグイン

概要
-------

シグニチャの各関数に対応する C 言語の関数を持つブリッジセルタイプを生成
します。C 言語のソースコードからは、この関数を呼び出すことで、ブリッジ
セルを経由して、TECS のセルの受け口関数を呼び出せます。

別々に tecsgen で生成された CDL ファイルのコンポーネント同士を結合させる
場合や、TECS のコンポーネントを、TECS を使わない C 言語のコードから利用
する場合に使用できます。

逆方向 (TECS から C 言語の関数を呼び出す) は、TECS2CBridgePlugin プラグ
インリファレンスを参照してください。

プラグイン種別
----------------------------

シグニチャプラグインです。対象はシグニチャです。

構文
----------------------------

 .. code-block:: tecs-cdl

  generate( C2TECSBridgePlugin, (シグニチャ名), "(オプション)" );

シグニチャは、generate の記述よりも前に定義されている必要があります。

オプション
----------------------------

オプションが複数ある場合は、','(コンマ)で区切ります。

.. list-table::
   :header-rows: 1
   :widths: 25 25 50

   * - オプション
     - 既定値
     - 説明
   * - ``prefix=PREFIX``
     - (なし)
     - 生成される各関数名の前に PREFIX を付加します。
   * - ``suffix=SUFFIX``
     - (なし)
     - 生成される各関数名の後ろに SUFFIX を付加します。
   * - ``header_name=name``
     - ``C2TECS_(シグニチャのグローバル名).h``
     - 生成されるヘッダファイルの名前を指定します。``gen`` ディレクトリの下に ``name.h`` として出力されます。拡張子 ``.h`` を省略した場合は補われます。

生成されるもの
----------------------------

シグニチャのグローバル名を ``sigGlobalName`` とします。

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 生成物
     - 説明
   * - ブリッジセルタイプ ``nC2TECS::t`` + ``sigGlobalName``
     - ネームスペース ``nC2TECS`` の下に置かれます。シングルトンで、呼び口 ``cCall`` (シグニチャは対象のシグニチャ) を持ちます。このセルタイプは実際にはアクティブではありませんが、警告 W1002 を避けるため ``active`` が指定されています。
   * - C 言語の関数
     - シグニチャの関数ごとに、``(PREFIX)(関数名)(SUFFIX)`` という名前の関数が、セルタイプのコードとして自動生成されます。関数の本体は、呼び口の関数 ``cCall_(関数名)`` を呼び出して、その戻り値を返します。
   * - ヘッダファイル
     - 生成された関数のプロトタイプ宣言を含みます。インクルードガードは ``(sigGlobalName)__h`` です。

生成時に、ブリッジセルタイプの名前と、セルを作成して ``cCall`` を目的のセルに結合する旨のメッセージが出力されます。

使用方法
----------------------------

目的のセルの受け口のシグニチャに対して、プラグインを generate します。
その後、生成されたブリッジセルタイプのセルを作成し、呼び口 ``cCall`` を、
C 言語から呼び出したい受け口に結合します。

 .. code-block:: tecs-cdl

  // signature sSignature, cell CellToBeCalledFromC は定義済みとします

  generate( C2TECSBridgePlugin, sSignature, "prefix='Sig'" );  // nC2TECS::tsSignature セルタイプを生成
  cell nC2TECS::tsSignature C2TECSBridge {                    // ブリッジセルを生成 (目的セルに結合)
     cCall = CellToBeCalledFromC.eEntry;
  };

C 言語のソースでは、``gen`` ディレクトリの下に生成されるヘッダファイル
を ``#include`` すると、シグニチャの関数を呼び出せます。

TECS ジェネレータの実行に成功した場合でも、コンパイル時、リンク時に関数名の衝突が
発生する可能性があります。``prefix`` または ``suffix`` オプションを指定
して、関数名をユニークなものにしてください。

別々にジェネレートされた CDL ファイルのコンポーネントを結合させるのに使
用する場合、両方の CDL ファイルで用いられているセルタイプに関わる ``.o``
(リロケータブルオブジェクト) を二重にリンクしないように注意が必要です。

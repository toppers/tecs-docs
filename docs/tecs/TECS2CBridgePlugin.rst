TECS2CBridgePlugin プラグインリファレンス
===================================================

名前
-------

  TECS2CBridgePlugin ... TECS のセルから C 言語の関数を直接呼び出すためのシグニチャプラグイン

概要
-------

シグニチャの受け口関数が、同じ名前の C 言語の関数を呼び出す、ブリッジ
セルタイプを生成します。TECS のセルの呼び口を、このブリッジセルの受け口
に結合すると、呼び出しが C 言語の関数に中継されます。TECS を使わずに記
述された既存の C 言語の関数を、TECS のコンポーネントから利用する場合に
使用できます。

逆方向 (C 言語から TECS の受け口関数を呼び出す) は、C2TECSBridgePlugin
プラグインリファレンスを参照してください。

プラグイン種別
----------------------------

シグニチャプラグインです。対象はシグニチャです。

構文
----------------------------

 .. code-block:: tecs-cdl

  generate( TECS2CBridgePlugin, (シグニチャ名), "" );

シグニチャは、generate の記述よりも前に定義されている必要があります。

オプション
----------------------------

オプションはありません。第 3 引数には空文字列を指定します。

生成されるもの
----------------------------

シグニチャのグローバル名を ``sigGlobalName`` とします。

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 生成物
     - 説明
   * - ブリッジセルタイプ ``nTECS2C::t`` + ``sigGlobalName``
     - ネームスペース ``nTECS2C`` の下に置かれます。シングルトンで、対象のシグニチャの受け口 ``eEnt`` を持ちます。受け口はインライン (``inline``) 指定です。
   * - 受け口関数の本体
     - シグニチャの関数ごとに、同じ名前と同じ引数の C 言語の関数を呼び出し、戻り値があれば返します。セルタイプのコードとして自動生成されます。
   * - ヘッダファイル ``gen/(sigGlobalName).h``
     - 呼び出される C 言語の関数のプロトタイプ宣言を含みます。``global_tecsgen.h`` を ``#include`` します。ヘッダの拡張子は tecsgen が決めます (通常は ``.h``)。

生成時に、ブリッジセルタイプの名前と、呼び元のセルの呼び口をこのブリッジセルの受け口 ``eEnt`` に結合する旨のメッセージが出力されます。

使用方法
----------------------------

呼び出したい C 言語の関数に対応するシグニチャに対し、プラグインを
generate します。その後、生成されたブリッジセルタイプのセルを作成し、呼
び元のセルの呼び口を、ブリッジセルの受け口 ``eEnt`` に結合します。

 .. code-block:: tecs-cdl

  // signature sSignature は定義済みとします

  generate( TECS2CBridgePlugin, sSignature, "" );   // nTECS2C::tsSignature セルタイプを生成
  cell nTECS2C::tsSignature TECS2CBridge {          // ブリッジセルを生成
  };

  cell tCaller Caller {
     cCall = TECS2CBridge.eEnt;                     // 呼び元の呼び口を結合
  };

C 言語の関数は、シグニチャの関数と同じ名前、同じ引数で、利用者が定義し
ます。生成されたヘッダファイルにそのプロトタイプ宣言があります。

 * 関数名はシグニチャの関数名がそのまま使われます。別のセルタイプが同じ名前の C 言語の関数を持つ場合など、名前が衝突しないようにしてください。
 * ブリッジセルタイプはシングルトンなので、ブリッジセルは 1 つだけ作成できます。
